## Portability defects caught before tagging

The pre-tag matrix correctly caught two release-boundary portability issues:

1. macOS lacks Linux `/proc` process-start ticks. TUI run-marker recovery now
   falls back to a non-signalling PID liveness check and preserves another live
   client's marker.
2. Python 3.12 adds an empty `type_params` field to function AST nodes. The
   component checker removes only that version-added empty field and requests
   explicit empty-field dumps where supported, preserving one compatibility
   identity without accepting source drift.

Both corrections were committed independently, rerun through the complete
local suite, pushed to both remotes, and proven by the final branch, tag, and
TestPyPI matrices.
