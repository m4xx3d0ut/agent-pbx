## Operational boundary

The standard daemon uses the legacy adapter for discovery and existing
bindings. That adapter cannot perform effectful durable cutovers. Live
qualification needs a host adapter that binds immutable artifact, config,
route and transport evidence to the selected runtime. Synthetic managed-clone
and console coverage does not qualify a deployed user appliance.

No workstation activation, branch merge, tag, remote push, or package index
publication formed part of this local qualification.
