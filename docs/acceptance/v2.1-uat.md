delta released as Agent PBX 2.1.0. The v2.0 architecture and portable baseline
remain documented in [the v2.0 acceptance record](v2-uat.md).

## Host qualification

The workstation migration was performed with the TUI stopped and a fresh
backup/rollback point retained. Operators were migrated and reconciled before
starred Agents. The qualification covered:

- root Operators and their retained edit/review forks;
- starred Agents with existing visible and hidden tmux/Codex sessions;
- same-server `outer_if_present` attachment from the workstation's outer tmux;
- native right-pane geometry and resize changes;
- Codex popup open/cancel/redraw behavior;
- pop-out and pop-in without restarting Codex;
- daemon and TUI restart with mapping reconciliation;
- desktop Linux and Android/Termux-over-SSH keyboard and scrollback behavior;
- managed workspace launch and post-dialog selection;
- alert cycling and acknowledgement;
- Joplin response capture and title generation.

The final adopted state leaves managed Agents and Operators popped into Agent
PBX, so no additional outer tmux tabs need to be tracked during normal work.

## Compatibility and rollback

Version 2.1 retains polling/nohup mode, Thread, HTTP refresh, and captured
terminal fallback. Native tmux remains the preferred local path. The additive
schema 29 migration is covered by the existing backup, dry-run, apply, verify,
and rollback workflow.

The workstation rollback point includes the prior database, configuration,
managed Codex fragments, runtime mappings, package state, and Git references.
Healthy Codex and tmux processes are preserved during package rollback. Backup
retention remains at least seven days after release activation.
