# Agent PBX 2.4.0rc2

Agent PBX 2.4.0rc2 is the second release candidate for the v2.4 durable
engineering control-plane cycle. It contains the complete
[v2.4.0rc1 feature boundary](v2.4.0rc1.md) plus one narrowly scoped
cross-platform validator repair found by the immutable RC1 GitHub matrix.

## RC1 qualification finding

The RC1 Linux/Python 3.12 lane found that GitHub's hosted Python tool-cache can
install the interpreter already running Agent PBX with a group-writable mode.
The durable-helper registry rejected that interpreter before validation, even
though replacing the process's own executable would already compromise the
running control plane. Linux/Python 3.10 passed and the failure was deterministic
across the helper validation cases.

RC2 permits only the resolved executable that is already running Agent PBX to
use that distribution mode. A separately configured validator interpreter
remains subject to the strict no-group-or-world-write rule. RC2 retains:

- strict symlink resolution to one existing executable;
- regular-file and owner-execute requirements;
- isolated `python -I -S` syntax compilation without helper execution;
- private validation directories and no inherited standard input or output;
- before/after device, inode, type, mode, owner, link, size, and timestamp
  identity comparison; and
- fail-closed validation receipts and helper lifecycle transitions.

## Release posture

RC1 remains immutable and is not published as a GitHub Release or production
package after its matrix failure. RC2 must pass the complete Linux/macOS and
Python 3.10/3.12 release matrix, distribution checks, clean-wheel installation,
TestPyPI Trusted Publishing, and registry-hash verification before a GitHub
prerelease is created.

All v2.4 engineering subsystems remain additive and default-disabled. See the
[complete RC1 notes](v2.4.0rc1.md), the
[v2.4 acceptance record](../acceptance/v2.4-uat.md), and the repository
changelog for the full feature, migration, rollback, and security boundary.

## Install the candidate

After TestPyPI qualification:

```bash
python -m pip install --index-url https://test.pypi.org/simple/ \
  --extra-index-url https://pypi.org/simple/ \
  agent-pbx==2.4.0rc2
```
