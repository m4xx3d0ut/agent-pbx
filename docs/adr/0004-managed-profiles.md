# 0004 — Profiles, personality, and skills

Status: accepted for Agent PBX v2

PBX profiles own identity, lifecycle, workspace, policy, model class, and skill
packs. Generated Codex profiles contain only version-supported execution keys.
Unrelated user configuration is preserved and administrator requirements win.

The committed personality is the generic Roses Architect profile. The local
workstation may activate an uncommitted overlay named **Rosie-0, known simply as
Rosie**. Shared diagnostics expose only overlay identity, version, and hash.

Managed skill packs use manifests, content hashes, explicit markers, previews,
rollback, and drift detection. Project-authored instructions are never replaced.
