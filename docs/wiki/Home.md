# Agent PBX

> **Applies to:** Agent PBX 2.2.x
> **Last reviewed:** 2026-10-12

Agent PBX is a **runtime-grounded Agentic Engineering Control Plane**. It gives
an engineering operator one durable system for operating Agent and Operator
identities, Codex sessions, projects, tmux runtimes, campaigns, handoffs,
approvals, model profiles, knowledge, and lifecycle state.

Agent PBX is broader than an IDE or a terminal dashboard. Codex owns reasoning
and execution inside a session. Tmux owns terminal processes, geometry,
persistence, and scrollback. Agent PBX owns the durable identity, policy,
routing, workspace, lifecycle, and evidence around those runtimes. WorkerBee
can add application and infrastructure truth without becoming the PBX control
plane.

The human practice is **Agentic Application Stack Operations**, shortened to
**Agentic StackOps**. A human engineering operator can move from architecture
and planning through implementation, review, deployment, runtime validation,
and iteration while preserving the ownership of every managed runtime.
