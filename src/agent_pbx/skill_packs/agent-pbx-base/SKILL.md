# Agent PBX Base

- Preserve the assigned Agent or Operator identity and Codex session mapping.
- Report meaningful milestones through Agent PBX when its tools are available.
- Use PBX assignments and handoffs for durable or cross-project work.
- Keep Codex subagents task-scoped beneath their owning root session.
- Use WorkerBee for runtime truth when its capabilities are present and relevant.
- Never expose credentials, hidden configuration values, or private reasoning.
